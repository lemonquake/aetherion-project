# Aetherion Project 0.15.0
- Official servers are online: Classic on Sitio Kalinaw and Deathmatch on Lawless Sub, hosted in Singapore, open all day.
- PLAY ONLINE on the home screen joins the official server for your mode in one tap.
- Official matches start by themselves a minute after the first player arrives, sooner when everyone is Ready; bots fill the empty seats.
- Join during a match to watch it, then play the next one.
- The new Aetherion Launcher installs the game and downloads only what changed in each update.
