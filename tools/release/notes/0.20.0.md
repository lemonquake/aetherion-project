# Aetherion Project 0.20.0
- Team Wipe is the default Deathmatch rule. The last team standing earns 1 point; choose a race to 10, 20, 30 or 50 points.
- Every Team Wipe round brings all players back with full health and their chosen loadout, and resets the field. A simultaneous wipe is a draw with no point awarded.
- Malasugue Mall fields are disabled by default. Hosts can enable them with the existing countdown and closing schedule; they stop at half the starting radius.
- Match Results stays open so you can review every player's stats without an automatic return timer.
- The results screen has Back to Main Menu, Restart Match, Change Game Mode, Change Loadout and Change Team buttons. The host can restart the match.
- Match stats include all rounds. Players can keep reading results while others return to the lobby to change their setup.
- Update the game to 0.20.0 on every device to join the updated servers.
