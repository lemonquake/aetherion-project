# Review brief

Seven numbered views of the same multiplayer team-shooter map, each captured twice from the same camera at the same
time of day: view<N>_A.png and view<N>_B.png (1600x900, real-time engine captures). Interior views are lit by a
work light on the camera.

Criterion: for each view, which capture looks more like a finished, shippable game environment, as opposed to an
unfinished procedural placeholder (consider surface detail and texture artefacts, believable architecture and
dressing, readability, and visual cohesion). Then give one overall choice across all seven views.

Use only these images. No numerical quality ratings. If you see no clear advantage, say so but still choose.

Return:
- per view: winner A or B, clear advantage true/false, one line of observed basis
- overall winner: A-set or B-set is not meaningful (labels are shuffled per view), so instead report the count of
  views won by the capture you judged more finished, and
- the single largest remaining gap you see in the better captures (one defect, with the view it is visible in),
  and an observable recheck condition for it.
