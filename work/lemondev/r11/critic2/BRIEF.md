# Review brief

Six numbered views of the same multiplayer team-shooter map, each captured twice from the same camera at the same
time of day with the same capture procedure: view<N>_A.png and view<N>_B.png (1600x900, real-time engine
captures). Interior views (5, 6) are lit by a work light on the camera.

Criterion: for each view, which capture looks more like a finished, shippable game environment, as opposed to an
unfinished procedural placeholder (surface detail and texture artefacts, believable architecture and dressing,
readability, visual cohesion).

Use only these images. No numerical quality ratings. If you see no clear advantage, say so but still choose.

Return:
- per view: winner A or B, clear advantage true/false, one line of observed basis
- evidence status: VALID, or UNVERIFIED with the reason for any pair that is not comparable
- the single largest remaining gap you see in the captures you judged better (one defect, the view it is
  visible in), and an observable recheck condition for it.
